# AS valve reference (optional)

Положите сюда EMF/PNG из Automation Studio:

- готовый 5/2 соленоид + пружина;
- фрагмент с глушителем на выхлопе 3/5.

После появления файлов можно пиксельно сверить с `tools/as_extract/out/captures/valve_5_2_ugo.*`.

Эталон AS 5/2: клетка `2M×2M`, орган `M×M` в нижней половине бока, пружина `1.38M×M` / 3 пика, глушитель = квадрат+X.
