# TEAM_GUIDE — как работает команда MechSim

Команда: **Роман** (архитектура, ошибки UX/UI, мерж), **Иван Борисович** (фичи), **Матвей и Даня** (проверка и оценка).

**Главное:** весь git делает ИИ-агент. Вы говорите ему по-русски, что нужно. В терминале руками — ничего.

## Цикл одной фичи

```text
Иван/Роман: «агент, новая фича …» → агент кодит и открывает демо
    ↓ автор доволен: «открой PR»
Матвей/Даня: «агент, скачай PR #N и открой демо» → проверка в Godot
    ↓
баги → список комментарием в PR → автор: «исправь замечания» → проверка снова
нет багов → «зелёный свет» в PR
    ↓
Роман жмёт Merge → все: «агент, обнови проект»
```

## По ролям

### Иван Борисович — фичи

1. Новый чат агента → «новая фича: …» (первый раз на машине — стартовый промт из [ONBOARDING.md](ONBOARDING.md) §5.1).
2. Смотрите демо, говорите агенту, что поправить.
3. «Запушь и открой PR» → сообщаете Матвею/Дане номер PR.
4. Пришли замечания → «агент, исправь замечания из PR #N».

### Роман — фичи + UX/UI-ошибки + мерж

- Тот же цикл, что у Ивана.
- Плюс разбирает ошибки UX/UI, которые нашла команда.
- Мержит только PR с зелёным светом от тестировщиков.

### Матвей и Даня — проверка и оценка

1. Получили номер PR → «агент, скачай PR #N и открой демо».
2. Проверяете в Godot: работает? удобно? логично?
3. Вердикт — комментарием в PR: список багов **или** «зелёный свет».
4. Ничего не чините и не пушите — это работа разработчика.

## Чтобы не было мусора

- **Одна фича за раз** на разработчика: новую не начинаем, пока старая не влита.
- Ветки, коммиты, пуши, PR — только агент. Сами ветки не создаём и не удаляем.
- **Issues — только для багов.** Фичам Issue не нужен: PR и есть задача. Баг из приложения: Помощь → «Сообщить об ошибке…» — Issue создастся сам.
- Обсуждение фичи — в комментариях её PR, не в личных чатах.
- Идеи «на потом» — одной строкой в **Discussions**.
- Агент просит подтвердить непонятное про git (push, force, reset) — стоп, спросите Романа.

## Фразы для агента

- «Новая фича: …» — начать работу.
- «Открой демо» — показать результат в Godot.
- «Запушь и открой PR» — отправить на проверку.
- «Скачай PR #N и открой демо» — посмотреть чужую фичу.
- «Исправь замечания из PR #N» — доработать по вердикту.
- «Обнови проект» — после мержа.
