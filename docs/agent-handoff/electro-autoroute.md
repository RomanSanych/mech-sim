## Решения пользователя

1. **Полный объём:** и расстановка элементов по зонам, и разводка жил.
2. **Групповые линии (rail):** создавать, если нужны.
3. **Обрыв:** только для длинных связей, которые иначе дают **много пересечений**.
4. **Коридоры:** **A — фиксированные коридоры** между зонами (улицы); не свободный кратчайший поиск.
5. **Политики:** разные для **силы** и **управления**.
6. **Канон управления:** «табличная» релейная схема — справа катушки/лампы/исполнители; в их цепях слева/в ряду — ключи/контакты, ведущие к срабатыванию.
7. **Область применения:** общий алгоритм для всех новых схем агента.

## Зоны (из эталона + канон п.6)

Слева → направо (черновик):

| Зона | Содержимое |
|------|------------|
| A | Питание / PE (`supply`, `psu`, вводные XT) |
| B | Автоматы / УЗО (`mcb`, `rcd`) — ряд/столбец |
| C | Цепи управления: органы + контакты в логике катушки (ключи в цепи) |
| D | Катушки / лампы / исполнительные УГО (правый край «таблицы» управления) |
| E | Групповые линии + полевые XT |
| F | Вынесенные контакты аппаратов (device-table), если нужны отдельно от C |

Сила и управление **не смешивать** в одном коридоре без нужды.

## Политики трасс (черновик)

### Управление
- Ортогональ, мало изломов (1–2).
- Горизонтальные «строки» логики к катушке/лампе справа.
- Общие возвраты (A2, X2, N-подобные) → **rail**; rail создавать при нескольких потребителях одного потенциала.
- Обрыв — если иначе частые пересечения чужих строк/столбцов.

### Сила
- Короткие stubs от QF; магистрали питания отдельно от строк управления.
- Длинный силовой «через весь щит» → обрыв чаще, чем змейка через зону C/D.

## Коридоры (п.4 = A)

- Заранее заданные каналы между зонами (верт. у rail / гориз. строки управления / силовые магистрали).
- Трасса предпочитает коридоры даже ценой небольшой длины.
- Свободный A* по всей плоскости — не основной режим v1.

## Прототип

`ElectroAutoroute.arrange` — зоны A…F, коридоры (ввод автоматов, плюс, возврат), обрыв длинной силы через таблицу. Кнопка авторазводки вызывает его. Эталон на диске не перезаписывается: маркер `test/.agent_autoroute` прогоняет алгоритм при открытии.
