# Agent handoff

Снимки прогресса для новых чатов/агентов в этом репо.

| Файл | Назначение |
|------|------------|
| `CURRENT.md` | Куда продолжать **сейчас** (обновлять после подэтапа) |
| `report-thermal-viz-2026-10-22.md` | Репорт: тепловизор/КЗ + **инцидент wipe `symbol_geom.gd`** |
| `wire-break-gost.md` | Обрыв линии + групповая взаимосвязь (ГОСТ 2.702 / 2.721) |
| `rotary-and-motors.md` | Этап ППЦ + пневмомоторы |
| `sensors.md` | Датчики (A1 принят; A2 на паузе) |
| `../AGENTS.md` (корень репо) | Входная шпаргалка |

## Зачем не один чат навсегда

Длинный чат копит ложные решения и жрёт токены. Правила живут в `.cursor/rules` + handoff; чат — только текущий кусок работы.

## Обновление handoff

Агент после закрытия подэтапа правит `CURRENT.md` (статус, демо, следующий шаг) и при необходимости секцию статуса в файле этапа.
