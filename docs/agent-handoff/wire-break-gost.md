# Обрыв / групповая линия (ГОСТ 2.702 + 2.721)

**Статус:** переработка UX (2026-10-17)  
**Демо:** `res://test/demo_cabinet_dense.mechsim.json`  
**Источник:** ГОСТ 2.702-2011 + ГОСТ 2.721-74

## Модель

### A. Обрыв линии

- Свойства провода → **«Визуально оборвать линию»** / **«Восстановить линию»**.
- Хвосты **4 клетки** по нормали порта у каждого конца; середина не рисуется.
- На конце — стрелка (−>/←−) и **номер провода за стрелкой** (одинаковый на обоих концах).
- `wire.broken`; электрика / 3D / net не рвутся.

### B. Групповая линия = rail УГО

- В библиотеке: **«Групповая линия»** (kind `rail`, как бывшая «Шина УГО»).
- Размещение / удлинение / Г-изгиб / поворот — как у шины.
- Провод с сонаправленным участком на линии: середина скрывается, остаются перпендикулярные ввод/вывод; номера у входа и выхода.
- Свойства провода → **«Убрать из групповой линии»** — скрытый участок сдвигается **вправо** на ~3 клетки.
- Старый `wire.group_id` + Shift-мультивыбор — **удалены**.

### C. Клеммник (связанный объём этапа)

- УГО: прямоугольник из ячеек **2×2**; полюс = 2×4 (верх/низ).
- В центре ячейки — залитый кружок Ø1 клетка (= порт, без отростка); над кружком номер.
- Обозначение колодки (`XT…`) — **tag над прямоугольником**.
- «Общая шина» — без внутренних перегородок.
- 3D: площадки номеров у винтов — сверху нечёт, снизу чёт; ближе к винтам.

## Инварианты

- Tips портов на `SCH_GRID`.
- Не трогать A1 / датчики / KK+КМ «заодно».
