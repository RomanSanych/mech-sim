## 3d_button_selfreturn_stop.png
- Обычная кнопка STOP без фиксации (самовозврат)
- Основание/крепёж/контактный блок как у варианта с фиксацией
- Отличается только клавиша (красная flush/купольная STOP, не гриб)
- Контактный блок на фото: ZB2-BE102, 1NC

# ugo_button_nc_no_detail.png (эталон геометрии)
- НЗ: левый горизонталь → наклон вниз-вправо до вертикального «крючка» правого вывода; пунктир вверх к актуатору «скоба»
- НО: левый горизонталь → наклон вверх-вправо с зазором до правого вывода; пунктир к актуатору
- Самовозврат: скоба (перекладина + засечки вниз); фиксация: скоба + флажок

# ugo_button_nc_exact.png — визуальный эталон НЗ
Наклон ПЕРЕСЕКАЕТ вертикальный крючок и выходит вправо (не «V»-стык).

# DXF «УГО элементов для электрических схем» — числовая разметка
Файл: `ugo_electrical_schemes.dxf` (копия из Downloads).
Канон в `dxf_ugo_canonical.json`, превью `ugo_button_nc_from_dxf_U582.png`.

| Символ | Блок DXF | Заметки |
|--------|----------|---------|
| НО контакт | U578 | наклон (−3,0)→(3,+3.46) |
| НЗ контакт | U580 | крючок (3,0)→(3,−4); наклон →(4,−4.04) |
| Кнопка НО | U584 | скоба y=8, ±3, ноги 2; пунктир стойки |
| Кнопка НЗ | U582 | контакт U580 + актуатор U584; стрелку на стойке U582 не рисуем (это другой квалификатор) |
| Катушка | U463 | 10×16 — совпадает с COIL_W/COIL_H |

В `electro_symbols.gd`: DXF_SCALE=10/3 (GAP DXF 3 → клетка 10). Порт контакта на ±20.
