# Переключатель SA
- 3d_switch_2pos_keaz_0_1.jpg — кулачковый 0–1 (KEAZ Optima), панель + модульный корпус сзади
- 3d_switch_3pos_1_0_2.png — переключатель 1–0–2, ручка + пакет контактов
- ugo_switch_positions_contacts_dots.png — эскиз УГО: вертикали = положения, горизонтали = контакты, точки = замыкание в положении

Правила от пользователя:
- Вертикальные линии = положения переключателя
- Горизонтальные линии = число/цепи контактов
- Чёрные точки на пересечениях = какие контакты замкнуты в каких положениях
- Пример: 3 положения → 3 вертикали; в поз.1 замкнут верхний контакт, в средней открыто, в поз.3 замкнут нижний
