# Электропроход: принятые уточнения (диалог)

Источник: ответы пользователя в чате. Реализация — по этому документу + рефы в `out/electro_refs/user/`.

## Объём

**Делаем:** ввод питания, шина DIN, клеммник DIN, БП, KL, KT, KM, KK, QF, УЗО, диф, концевой упор (только 3D), учебная симуляция электрики, лимит 2 провода на порт.

**Скипаем:** реле напряжения, розетка DIN (убрать из каталога), двигатели/SQ/FU и пр. вне текущего каталога. Дверца (лампа/кнопка/SA/гриб) — не ломать, уже ок.

**Порядок работ (всё пакетом):**  
1) правила схемы (≤2 провода/порт, DIN шаг 0.5) → 2) УГО → 3) 3D → 4) учебная симуляция.  
Остановки только если нужен визуальный ок пользователя.

## Ввод питания (XS)

- Не DIN-аппарат. Кабель из-под пола → кабельный ввод в щит → жилы с колеровкой ГОСТ.
- **УГО:** как сейчас — прямоугольник с подписями и выводами **вправо**.
- **3D:** кабельный ввод + цветные жилы (делать сразу, не откладывать).
- Варианты:
  - 1ф: L / N / PE (3 жилы)
  - 3ф + PE: L1 / L2 / L3 / N / PE (5 жил)
  - 3ф без PE: L1 / L2 / L3 / N (4 жилы)
- Колеровка проводов (ГОСТ, реф пользователя):
  - L / L1 — коричневый
  - L2 — чёрный
  - L3 — серый
  - N — синий
  - PE — жёлто-зелёный (стандарт; на таблице фаз не было — принять)
  - DC+: коричневый; DC−: по таблице серый / по шинам — чёрный для «минус» базы

## Шина

- Тип: латунная колодка на **пластиковой базе с креплением на DIN** (реф фото пользователя), не пятки к панели.
- База занимает **1 модуль** по длине рейки; шина стоит **поперёк** DIN (не вдоль).
- Цвета базы (выбор в параметрах):
  - голубой — нейтраль N
  - чёрный — минус
  - красный — плюс
  - зелёный — PE
  - коричневый — фаза L1
  - чёрный — фаза L2
  - серый — фаза L3
- Подпись вручную — да.
- Число отводов — параметр.

---

## DIN: шаг и ширины

- **1 модуль = 17.5 мм** = ширина корпуса 1P АВ.
- **Шаг перемещения по DIN = 0.5 модуля.**
- Клеммник: **0.5 модуля** на один полюс/клемму.
- Шина: база **1 модуль** (поперек).
- Канон (подтверждён, кроме шины/шага выше):

| Элемент | Канон | Модули |
|--------|--------|--------|
| QF 1P | IEK ВА47-29 | 1 |
| QF 3P | IEK ВА47-29 | 3 |
| УЗО 2P | ABB F202 / аналог | 2 |
| Диф 1P+N | IEK АВДТ | 2 |
| KT | EKF RT-SBA | 1 |
| KL | реле + DIN-колодка | 2 |
| KM | EKF КМЭ | 3 |
| БП | Mean Well DRA-60-24 | 2 |
| KK | тепловое (реф PTA) | 3 (как с КМ) |
| Клеммник | винтовой DIN | 0.5 × N |
| Концевой | — | ~0.5; только 3D |

Распиновка/сторона клемм: по даташитам и рефам самостоятельно; к пользователю — только если неоднозначно.

## Клеммник и лимит проводов

- Клеммник DIN — полноценно (УГО + 3D + параметры).
- **На порт УГО прибора ≤ 2 провода.** Больше — через клеммники/шины (как в реальности).

## БП (УГО)

- Таблица Конт.|Цепь слева и Цепь|Конт. справа — **норм** (стиль ОВЕН ПЛК210).
- Исправить: отступы сверху/снизу рамки; зазор между внутренними таблицами клемм; «Конт.» не должна залезать на линии ячеек.
- Параметры: Uin / Uout / Iout (+ подпись).

---

## Реле / KT / KM / контакты

- Контакты по умолчанию **столбиком под катушкой**; мехсвязь от **нижней грани** катушки.
- **Отнесённый контакт:** как у кнопок — **без рамки и без штриховой линии**.
- **KL:** УГО норм.
- **KT:** крест и его рамку сплющить по ширине до **1 клетки**; «улыбки» задержки на контактах — **в 2 раза больше**.
- **KM:** полукруг на силовом контакте должен стоять **на оси линии** провода.
- Параметры: U катушки, Iконт max, состав контактов; у KT — **уставка времени срабатывания** (Ton/Toff).

---

## АВ / УЗО / диф (УГО)

- Текущее — кривое. Делать **точно по рефам** `ugo_mcb_*`, `ugo_rcd_*`, `ugo_rcbo_*` (при необходимости сверить с сетью, итог = реф).
- В свойствах **нет** состояния вкл/откл.
- Переключение: **клик по рычагу на УГО и 3D в симуляции** (как кнопка) + авто по уставке/аварии.
- Параметры: In, кривая B/C/D, Icu, Ue; у УЗО/диф — IΔn, тип AC/A/B.

## Концевой упор

- Только 3D (на схеме УГО нет).
- Постановка: **авто по краям занятой DIN** и **вручную**.

## Симуляция (учебная)

- Ток, напряжение, нагрев, КЗ — уровень, достаточный новичку-электромонтажнику.
- Учебная модель: узлы/Ohm, In/кривая/IΔn → отключение, нагрев ~ I²t, КЗ как сверхток. Без дуги/полного R кабелей на первом проходе.
- Аппараты защиты срабатывают по параметрам; рычаг кликабелен вручную в sim.
