- 3d_rcd_abb_f202.png — ABB F202-AC 25A IΔn=0.03A 2P; на корпусе мини-схема УЗО (овал + контакты без креста/прямоугольника)
- ugo_rcd_2p_4p_single_and_multiline.png — УГО чистого УЗО: 2P/4P однолинейно и многолинейно; овал (дифф. трансформатор) + контакты + связь к овале; креста и прямоугольника нет
- ugo_rcbo_diff_switch_variants.png — УГО дифавтомата: крест (отключение) + прямоугольник на контакте (автоматическое) + овал дифф. защиты; 1/3 линии и 2P/4P многолинейно
- 3d_rcd_xray_principle.png — устройство для рентгена: 1 дифф. ТТ, 2 пороговый элемент, 3 исполнительный механизм, 4 цепь теста, 5 силовые контакты, T/R тест

Правила от пользователя:
- Крестик на линии = функция отключения (разъединитель/коммутация с разрывом)
- Прямоугольник на контакте = отключение автоматическое (тепло/электромагнит как у автомата)
- Чистое УЗО: овал + контакты, без крестика и без прямоугольника
- Дифавтомат = УЗО + автомат в одном корпусе → сочетание их УГО (крест + прямоугольник + овал)
