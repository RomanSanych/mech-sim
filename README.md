# MechSim

Учебный симулятор пневмо- и электросхем: 2D-схема (УГО ISO 1219 + электро) + 3D-цех + физика (давление, золотники, штоки, электросеть 24 V / 220 V, датчики). Параметры элементов — из каталогов производителей (Festo/Camozzi/SMC-класс).

- Движок: **Godot 4.7** (GL Compatibility, Jolt Physics).
- Запуск: открыть папку проекта в Godot → F5 (сцена `scenes/main.tscn`).
- Демо-сцены: `test/*.mechsim.json` (в приложении: Файл → Открыть).

Все работают через ИИ-агентов: git-операции выполняет агент, человек ставит задачу и принимает результат. Git знать не нужно — см. гайд ниже.

## Как мы работаем (кратко)

1. Задачи — **GitHub Issues** (шаблоны: Фича / Баг / QA-проверка). Идеи — **Discussions**.
2. Одна задача = одна ветка = один PR. В `main` и `dev` попадаем только через PR (защита включена).
3. Разработка: ветка от `dev` → PR в `dev`. QA-фиксы: ветка от `qa/pass-1`.
4. Визуальную приёмку делает человек по демо-сцене в Godot, не агент по скриншотам.
5. Баг из приложения: **Помощь → «Сообщить об ошибке…»** → Issue со скриншотом и сценой создаётся автоматически.

Подробный гайд для команды: **[docs/TEAM_GUIDE.md](docs/TEAM_GUIDE.md)**.
